# 🌊 Ocean Embedded

Multidimensional Ocean Observatory Platform combining satellite remote sensing with 3D subsurface Physics-Informed Neural Networks (PINNs).

## 📁 Repository Layout

- [`frontend/`](./frontend) — React 18 + Vite + Three.js + Tailwind CSS frontend application.

## 🚀 Quick Start (Frontend)

```bash
cd frontend
npm install
npm run dev
```
